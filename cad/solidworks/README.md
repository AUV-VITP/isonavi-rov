# Team CAD (SolidWorks)

The mechanical design of the six thruster build.

| Path | Contents |
| --- | --- |
| `ASSem/MAIN.SLDASM` | Top assembly |
| `ASSem/FRAME.SLDASM` | Frame: top and bottom plates on side supports, thruster mounts |
| `ASSem/enclosure.SLDASM` | Acrylic hull with end caps and seals |
| `ASSem/ELEC-SLED.SLDASM`, `ASSem/BATT-SLED.SLDASM` | Electronics and power sleds inside the hull |
| `ASSem/M080 Thruster.SLDASM` | Thruster |
| `ASSem/Gripper/` | Crank and slider gripper, its parts, screenshots and an exploded video |
| `Parts/` | Hull (`CAN-001` to `CAN-005`), O-rings, brackets, camera mount, frame plate, supports |
| `Drawings/FRAME.SLDDRW` | Frame drawing: top, front, side and isometric views |
| `renders/` | Exploded and labelled views, and the drawing sheet |
| `FRAME.mp4` | Exploded turntable of the frame assembly |

Open `ASSem/MAIN.SLDASM` in SolidWorks; parts are referenced from `Parts/`
and `ASSem/`.
